# Project Index

## Project: Personal Portfolio

A premium, minimalist personal portfolio designed to attract freelance clients and demonstrate technical + creative expertise. Built with vanilla HTML, CSS, and JavaScript featuring glassmorphism, gradient accents, dual theme support, and smooth animations.

## Quick Reference

- **Tech:** HTML5, CSS3 (Custom Properties), JavaScript (ES6+)
- **Design:** Glassmorphism, gradient borders/accents, dual theme (dark/light)
- **Typography:** Space Grotesk (headings), Inter (body), JetBrains Mono (code)
- **Animation:** Smooth & subtle (300–500ms), Intersection Observer scroll reveals
- **Target:** Freelance clients, business owners, startup founders
